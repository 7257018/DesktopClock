# DesktopClock 桌面时钟

Windows 11 桌面时间显示小组件，基于 Python + PyQt6 开发。

## 功能介绍

### 核心显示
- **当前时间**：支持 `hh:mm` 和 `hh:mm:ss`（含秒）两种格式，可切换
- **公历日期**：`yyyy-MM-dd` 格式
- **星期**：本地化星期名称（星期一 ~ 星期日）
- **农历日期**：如 `二〇二六年(丙午 马)七月初五`，含闰月支持（1900-2100），各部分可独立开关：
  - **农历年**：中文数字年份（二〇二六年），默认关闭
  - **天干地支**：六十年甲子（丙午），默认关闭
  - **属相**：十二生肖（马），默认关闭
  - **括号规则**：天干地支与属相至少开启一个时才显示括号，两者均关闭则无括号
  - 默认只显示月日（如 `七月初五`），按需组合年/干支/属相

### 外观定制
- **字体**：系统任意已安装字体
- **字号**：20–250 可调
- **透明度**：0–255 全范围可调
- **颜色**：单色模式下自定义任意颜色
- **渐变主题**：12 种内置渐变（彩虹、落日、海洋蓝、极光、烈焰等），支持流动动画
- **布局**：三行居中布局（时间 / 日期+星期 / 农历），日期与星期可并排同行或分行显示
- **高 DPI**：自动适配 4K / 高分辨率屏幕及系统缩放

### 实用功能
- **倒计时**：可设默认时长，托盘菜单一键启动 / 暂停 / 重置
- **秒表**：正向计时，托盘菜单控制
- **拖拽定位**：鼠标拖动时钟到桌面任意位置，自动记忆
- **固定位置**：锁定后不可拖动
- **窗口置顶**：可选时钟始终在最前
- **开机自启**：通过注册表实现，支持打包后 exe 和开发模式
- **系统托盘**：双击托盘图标显示/隐藏时钟，右键菜单操作全部功能
- **单实例保护**：防止重复启动，二次启动激活已有窗口

## 编译构建

### 方式一：一键脚本（推荐）

```bat
build.bat
```

脚本会自动安装依赖并打包，生成的 exe 位于 `dist\DesktopClock.exe`。

### 方式二：手动构建

```bash
# 1. 安装依赖
pip install PyQt6 pyinstaller

# 2. 打包为单文件 exe（无控制台窗口）
pyinstaller --onefile --windowed --name DesktopClock --clean --noconfirm clock.py

# 3. 生成文件位于 dist\DesktopClock.exe
```

### 构建选项说明

| 参数 | 作用 |
|------|------|
| `--onefile` | 打包为单个 exe 文件 |
| `--windowed` | 无控制台黑窗口（GUI 程序） |
| `--name DesktopClock` | 输出文件名 |
| `--clean` | 清理 PyInstaller 缓存 |
| `--noconfirm` | 覆盖输出目录无需确认 |
| `--icon=xxx.ico` | 自定义图标（可选） |

### 添加自定义图标

将 `.ico` 图标文件放在项目目录，构建命令追加 `--icon=你的图标.ico`。

## 用户指南

### 安装

1. 获取 `DesktopClock.exe`（从 `dist\` 目录或发布包）
2. 复制到任意目录（如 `C:\Program Files\DesktopClock\` 或桌面）
3. 双击运行

### 首次使用

1. 启动后时钟显示在桌面（默认白色文字，三行居中：时间 / 日期+星期 / 农历）
2. **右键托盘图标** → 「时钟设置」打开设置面板
3. 在「外观」选项卡调整字体、颜色、主题、显示内容
4. 显示内容复选框说明：
   - 显示日期 / 显示星期 / 显示秒钟 / 显示农历：基础开关
   - 显示农历年（二〇二六年）：默认关闭，开启后农历行带中文数字年份
   - 显示天干地支（丙午）：默认关闭，开启后农历行带干支
   - 显示属相（马）：默认关闭，开启后农历行带生肖
   - 日期与星期并排同一行：默认开启，关闭后日期和星期各占一行
5. 在「启动」选项卡开启「开机自启动」「时钟置顶」等

### 日常操作

| 操作 | 方式 |
|------|------|
| 移动时钟 | 鼠标按住时钟拖动 |
| 显示/隐藏 | 双击托盘图标，或右键 → 显示时钟 |
| 打开设置 | 右键托盘 → 时钟设置 |
| 启动倒计时 | 右键托盘 → 开始倒计时 |
| 启动秒表 | 右键托盘 → 开始计时 |
| 退出程序 | 右键托盘 → 退出 |

### 开机自启动

在设置 →「启动」选项卡勾选「开机自启动」即可。程序通过 Windows 注册表
`HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 实现自启，无需管理员权限。
若移动了 exe 位置，下次运行时自启路径会自动更新。

## 故障排查

### 启动后看不到时钟
- 检查托盘图标是否存在，双击托盘图标显示时钟
- 时钟可能在屏幕边缘外，右键托盘 → 显示时钟后检查
- 重置位置：删除注册表项 `HKCU\Software\Org\DesktopClock` 下的 `pos_x`/`pos_y`

### 时钟文字颜色与壁纸冲突看不清
- 右键托盘 → 时钟设置，更换颜色或切换渐变主题
- 调整透明度（「外观」选项卡）

### 开机自启动不生效
- 确认设置中「开机自启动」已勾选
- 检查注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 中是否有 `DesktopClock` 项
- 若 exe 已移动位置，手动运行一次程序即可自动更新路径
- 某些安全软件可能拦截注册表写入，需添加信任

### 双击 exe 无反应
- 首次运行 Windows Defender 可能扫描，等待片刻
- 检查任务管理器中是否有 `DesktopClock.exe` 进程
- 查看错误日志：`%USERPROFILE%\.DesktopClock\error.log`

### 农历日期显示异常
- 农历算法覆盖 1900–2100 年，超出范围显示公历原值
- 确认系统日期时间正确
- 若农历行缺少年份/干支/属相，在设置 →「外观」→ 显示内容中勾选对应选项
- 默认只显示农历月日（如 `七月初五`），需手动开启农历年/天干地支/属相

### 高 DPI 屏幕显示模糊
- 程序已启用高 DPI 支持，若仍模糊尝试右键 exe → 属性 → 兼容性 → 更改高 DPI 设置

### 程序无法退出
- 若托盘不可用，通过任务管理器结束 `DesktopClock.exe` 进程

## 技术说明

- **农历计算**：内置查表算法（1900-2100），无外部依赖，已通过春节、闰月等测试用例验证
- **单实例**：基于 `QSharedMemory` 实现，无文件锁残留
- **设置存储**：使用 `QSettings`（Windows 注册表），类型安全自动转换
- **错误处理**：全局异常捕获写入日志，渐变渲染异常自动回退单色，托盘不可用时自动降级
